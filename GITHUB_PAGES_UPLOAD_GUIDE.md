# LearnTech Kenya Website Upload Guide

## Step 1: Download Your Website Files

1. Download `learntech_website_complete.zip` from this chat
2. Extract it to a folder on your computer (e.g., `Downloads/learntech_website`)

## Step 2: Access Your GitHub Repository

1. Go to **github.com** and sign in to your account
2. Navigate to your repository: `github.com/danny6042/Learntech--kenya`
3. Click the green **Code** button → **Download ZIP** (or use GitHub Desktop if you have it installed)

## Step 3: Replace Old Files with New Ones

### Option A: Direct Upload (Easiest for Beginners)

1. In your GitHub repository, click **Add file** → **Upload files**
2. Click **Choose your files**
3. Select ALL files from the extracted `learntech_website` folder:
   - All `.html` files
   - `css/styles.css`
   - `js/main.js`
   - `images/learntech_logo.png`
   - `sitemap.xml`
   - `robots.txt`
4. IMPORTANT: Make sure to upload the `images/` folder and `css/` folder as well
5. Type a commit message: `Updated website with new SEO and design`
6. Click **Commit changes**

### Option B: Using GitHub Desktop (Recommended for Updates)

1. Download [GitHub Desktop](https://desktop.github.com/) if you don't have it
2. Clone your repository: `File → Clone repository → URL tab`
3. Paste: `https://github.com/danny6042/Learntech--kenya.git`
4. Choose a local path (e.g., `Documents/Learntech--kenya`)
5. Click **Clone**
6. Delete all files inside the cloned folder
7. Copy ALL files from the extracted ZIP into this folder
8. Open GitHub Desktop — you'll see all the changes
9. Type a summary: `Complete website rebuild with SEO`
10. Click **Commit to main** then **Push origin**

## Step 4: Verify Your Site is Live

1. Wait 2-5 minutes for GitHub Pages to rebuild
2. Visit: `https://danny6042.github.io/Learntech--kenya/`
3. Check that all pages load correctly:
   - Home page
   - Coding courses
   - Computer Skills
   - Contact page
   - About page

## Step 5: Submit to Google (CRITICAL for Reachability)

### 5.1 Google Search Console

1. Go to [Google Search Console](https://search.google.com/search-console)
2. Sign in with your Google account
3. Click **Add property** → **URL prefix** → Enter: `https://danny6042.github.io/Learntech--kenya/`
4. Verify ownership (choose **HTML file upload** method)
5. Download the verification file from Google
6. Upload it to your GitHub repository root (same folder as index.html)
7. Commit the file
8. Go back to Search Console and click **Verify**
9. Once verified, click **Sitemaps** in the left menu
10. Enter: `sitemap.xml` and click **Submit**

### 5.2 Test Your Sitemap

- Go to: `https://danny6042.github.io/Learntech--kenya/sitemap.xml`
- You should see a list of all your pages
- If it works, Google can now find all your pages automatically

### 5.3 Request Indexing (Speed Up Results)

1. In Google Search Console, go to **URL Inspection** (top bar)
2. Paste your homepage URL: `https://danny6042.github.io/Learntech--kenya/`
3. Click **Request Indexing**
4. Repeat for your most important pages:
   - `/coding.html`
   - `/computer-skills.html`
   - `/contact.html`

## Common Issues & Fixes

| Problem | Solution |
|---------|----------|
| Site doesn't load after upload | Wait 5-10 minutes, then hard refresh (Ctrl+Shift+R) |
| Images not showing | Make sure the `images/` folder was uploaded correctly |
| CSS looks broken | Make sure `css/styles.css` was uploaded to the `css/` folder |
| Google says "URL not found" | Check that GitHub Pages is enabled in repository Settings → Pages |
